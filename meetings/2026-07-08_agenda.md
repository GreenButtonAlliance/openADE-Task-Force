## GBA CMD Certification Application and Platform Updates
* CMD Application Updates
  * [FB_41] Manage ApplicationInformation Resource has been removed from the CMD Application
  * [FB_44] Manage Authorization Resource has been removed from the CMD Application
  * CMD Application version 2.13 is now available on the [GBA Website](https://www.greenbuttonalliance.org/certification-preparation-dc#toc3)
* CMD Certification Platform Updates
  * [FB_42] Manage Authorization Resource has been removed from the CMD Certification Platform
  * [FB_43] Manage ApplicationInformation Resource has been removed from the CMD Certification Platform
  * All GET and POST requests on the CMD Certification Platform now support Request Failure Diagnostics
    * Failure Diagnostics include the ability to report invalid OAuth 2.0 opaque access tokens
      * JWT formatted access tokens are not supported by the ESPI standard and will generate a warning on the CMD 
        Result Summary Report
      * Decodable bearer token (base64url(JSON:marker:sig)) access tokens will also generate a warning on the CMD 
        Result Summary Report
    * All access token content is masked by default but can be unmasked for debugging purposes
    * Return request status codes that do not match CMD Certification requirements will also activate the Request 
      Failure Diagnostic feature
    * The CMD Certification Platform now tracks resource UUID and atom self-link URLs to verify they are unique
      * Any resource that contains multiple UUIDs and/or multiple atom self-link URLs will generate a warning on the 
        CMD Result Summary Report
